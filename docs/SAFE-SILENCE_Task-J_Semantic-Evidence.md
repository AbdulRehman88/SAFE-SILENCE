# SAFE-SILENCE Task J — Semantic Innovation and Bounded Validity

## Scientific role

Task J turns locally observed ocean measurements into communication decisions. It is the
first core SAFE-SILENCE mechanism: prediction confidence is treated as fallible evidence,
not as permission for indefinite silence. A node may suppress a packet only while an
explicit validity contract remains active.

## Causal evidence

For each channel and current sensing time, the node computes:

- standardized innovation: absolute prediction error divided by predictive standard
  deviation with a training-scale floor;
- interval-breach ratio: distance outside the conformal interval divided by interval
  half-width;
- predictive uncertainty normalized by the training-only channel scale;
- observation-age/missingness evidence; and
- causal critical-event evidence generated by the frozen Task H rules.

The four continuous components are softly saturated to `[0, 1]` and combined using YAML
weights. Cross-channel aggregation uses the maximum so a rare dangerous channel cannot be
diluted by normal channels. Valid causal event evidence overrides all compression and sets
semantic risk to one. The current observation is available at the transmitting sensor;
future measurements are never used.

## Nominal decision policy

Actions follow the locked safety order:

1. `alert` for causal critical evidence;
2. `alert` for extreme semantic risk or interval breach;
3. `innovation` for material non-extreme risk;
4. `heartbeat` when the current validity contract expires;
5. `heartbeat` at the liveness limit; otherwise
6. `silent` while the bounded contract remains valid.

The validity horizon contracts monotonically as risk increases and never exceeds four
protocol steps. A new contract is created only by an actual transmission. Consequently,
the receiver can later distinguish silence inside a valid contract from silence after
expiry. Network loss remains unknown at this stage and is introduced in the failure model,
not silently conflated with environmental missingness.

## Leakage and interpretation contract

- Task I and Task H inputs are reverified against their SHA-256 manifests.
- Task H event rules remain training calibrated and causal.
- Nominal policy thresholds are fixed a priori and never optimized on test/external data.
- Primary 15-minute and secondary 60-minute results remain separate.
- Task J event recall is explicitly a pre-network upper bound, not delivered recall.
- Payload counts exclude headers, ACKs, retransmissions, and energy; those belong to the
  network simulator.
- Task I intervals are not claimed to preserve nominal coverage under event or site shift.

## Outputs

- `results/task_j/evidence/<protocol>/<site>.parquet`: row-level evidence, action,
  decision reason, contract identifier, age, validity horizon, and semantic payload size.
- `results/task_j/semantic_decision_metrics.csv`: protocol/site/role action counts,
  transmission fraction, payload reduction, pre-network event recall, and false-alert rate.
- `results/task_j/task_j_summary.json`: causal declarations, verified-input counts,
  protocol totals, configuration hash, and output hashes.
